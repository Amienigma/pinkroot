# PINKROOT

![PINKROOT](public/cover.jpg)

*I remember every moment with you.*

**Live:** https://amienigma.github.io/pinkroot/

A pink-on-black AI gateway console: API keys, providers, plugins, a terminal, logs and settings, all in one React app. Every key, provider and number in it is demo data.

## Run it
```bash
npm install
npm run dev
```
